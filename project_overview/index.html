项目简介

🎯

核心价值

证件照智能处理平台，采用前后端分离架构，提供智能裁剪和背景替换功能。

💡

技术亮点

  • FastAPI 后端图像处理
  • Pillow + OpenCV 图像处理
  • Vue 3 + TypeScript 前端
  • 前后端独立 .env 配置

架构全景

技术栈

前端

快速开始

1

生成环境配置

bash
python init-env.py
2

启动后端

bash
cd aips-api && pip install -r requirements.txt && uvicorn main:app --reload
3

启动前端

bash
cd aips-web && npm install && npm run dev
服务地址
后端 APIhttp://127.0.0.1:8000
前端http://localhost:5173
